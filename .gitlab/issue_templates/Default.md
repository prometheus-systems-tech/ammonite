# Welcome to the Ammonite issue tracker!

To report a bug with Ammonite, please select the 'Bug' template under 'Description' above.

To request a feature, please select the 'Feature' template under 'Description' above.

To report a shortcoming, something that Ammonite currently does not as good as you wish it would, select the 'Shortcoming' template under 'Description' above.

If you need help regarding the usage or configuration of Ammonite, or have a concern not covered by anything described here, please feel free to open an issue.
